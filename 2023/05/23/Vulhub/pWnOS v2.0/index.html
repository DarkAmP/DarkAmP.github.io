0X01 信息收集

目标主句ip 10.10.10.100

nmap扫描端口，看看有哪些服务

发现22和80，查看80端口搭建服务

dirsearch扫子目录

查看一下登录页面和注册页面，应该有管理员用户

先注册一个账号登录进去

这是注册页面，不确定是否有sql注入，暂时不看，

然后下一步注册好之后登录进去，

里面什么都没有，查看源代码

应该不是这个页面，这些都没有什么线索

去/blog页面查看一下

发现新的线索，是一个博客网页

查看一下网页源代码

发现是用的Simple PHP Blog 0.4.0

searchsploit

发现有已知漏洞

把两个exp拷贝到桌面看一下

由于OSCP官方是在考试的时候限制metasploit的使用次数的，这里优先查看第一个

使用searchsploit -m /地址 来拷贝内容

查看了两个exp发现没有什么可以直接利用的信息，

然后去翻阅人家的wp后，还是决定使用一下msf

设置完host和usi之后，msf成功了

使用他给我们创建的账号，hi8vnq:230Dum

多次尝试发现msf给我创建的账号密码登录不进去

于是直接msf上面shell一下

使用命令 python -c “import pty;pty.spawn(‘/bin/bash’)”来构造伪shell

由于不能复制粘贴，所以打错了好几次。还是不太熟练。

直接查看MySQL的连接配置

发现root的登录密码

重新打开一个终端，ssh连接

这边直接就连接成功了

显然这不是我想要的效果，我并不想利用msf来打入

所以尝试一下利用sql注入来打入

回到刚刚最初的登录界面

利用单引号尝试报错

暴露出来的信息还是蛮多的

利用brup重发器来手工注入一下
