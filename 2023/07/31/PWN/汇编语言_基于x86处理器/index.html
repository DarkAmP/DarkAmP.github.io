EFLAGS 包含了独立的二进制位，用于控制CPU的操作，或是反映一些CPU操作的结果。

控制标志位
控制CPU的操作。例如，它们能使得CPU每执行一条指令后进入中断；在侦测到算数运算溢出时中断执行；进入虚拟8086模式，以及进入保护模式
程序能够通过设置EFLAGS寄存器中的单独位来控制CPU的操作，比如，方向标志位和中断标志位。
状态标志位
反映CPU执行的算术和逻辑操作的结果。其中包括：溢出位、符号位、零标志位、辅助进位标志位、奇偶校检位和进位标志位。

  • 进位标志位(CF)，运算时最高有效位置向更高位借位或进位，设置该标志位（无符号溢出）
  • 溢出标志位(OF) 目标操作数结果大于该数范围时置1（两正相加为负，两负相加为正）
  • 符号标志位(SF)，算术或逻辑操作产生负结果时，设置该标志位
  • 零标志位(ZF)，算术或逻辑操作产生的结果为零时，设置该标志位
  • 辅助进位标志位(AC)，算术操作在8位操作数中产生了位3向位4的进位时，设置该标志位
  • 奇偶校检位(PF)，结果的最低有效字节包含偶数个1时，设置该标志位，否则清除。一般情况下，如果数据有可能被修改或者损坏时，该标志位用来进行错误检测

Tiny，所有数据和代码都放在一个段内，其数据和代码都是近访问。Tiny程序可以写成.COM文件的形式，COM程序必须从0100H的存储单元开始。这种模型一般用于小程序。
Small，所有数据放在一个64KB的数据段内，所有代码放在另一个64KB的代码段内，数据和代码也都是近访问的。这是一般应用程序最常使用的一种模型。
Medium，代码使用多个段，一般一个模块一个段，而数据则合并成一个64KB的段组。这样，数据是近访问的，而代码则可远访问。
Compact，所有代码都放在一个64KB的代码段内，而数据则可放在多个段内，形成代码是近访问的，而数据则可为远访问的格式。
Large，代码和数据都可以都可用多个段，所以数据和代码都可以远访问。
Huge，与Large模型相同，其差别是允许数据段的大小超过64KB。

伪指令

伪指令，是嵌入源代码中的命令，由汇编器识别并执行。伪指令不在运行时不执行，但是它们可以定义变量、宏和子程序；为内存段分配名称，执行许多其他与汇编器相关的日常任务。默认情况下伪指令不区分大小写。

指令

指令是一种语句，在汇编编译时变得可执行。汇编器将指令翻译为机器语言字节，并在运行时由CPU加载和执行。一条指令由如下四个部分组成：

  1. 标号(可选)
  2. 指令助记符
  3. 操作数
  4. 注释(可选)

[label:] mnemonic [operands] [;comment]

标号

标号(label)是一种标识符，是指令和数据的位置标记。标号位于指令的前端，表示指令的地址。同样，标号也位于变量的前端，表示变量的地址。标号有两种类型：数据标号和代码标号
数据标号标识变量的位置，它提供了一种方便的手段在代码中引用该变量。比如
count DWORD 100
定义了一个名为count的变量
汇编器为每个标号分配一个数字地址。可以在一个标号后面定义多个数据项。在下面的例子中，array定义了第一个数字(1024)的位置，其他数字在内存中的位置紧随其后：
array DWORD 1024, 2048
DWORD 4096, 8192
程序代码区的标号必须用冒号结束。代码标号用作跳转和循环指令的目标。如下面的JMP指令创建一个循环，将程序控制传递给标号target标识的位置:
target:
mov ax, bx
jmp target
代码标号可以与指令同一行也可以自己独立一行:
L1: mov ax,bx
L2:
标号命令规则遵循标识符

指令助记符

标记一条指令的短单词，如：

MOV 分配数值 MUL 两个数值相乘
ADD 两个数值相加 JMP 跳转到一个新位置
SUB 从一个数值减去另一个 CALL 调用一个子程序

操作数

操作数是指令输入输出的数值。汇编语言指令中的操作数范围是0~3个，每个操作数可以是寄存器、内存操作数、整数表达式和输入输出端口。
操作数具有顺序，当有多个操作数时，第一个是目的操作数，第二个被称为源操作数，一般情况下目的操作数内容由源操作数修改，如
imul eax,ebx,5 ebx与5相乘，结果存放在eax寄存器中
操作数分为立即数(数字或文本表达式)、寄存器操作数(使用CPU内已命名寄存器)和内存操作数(引用内存位置)

NOP(空操作)指令

最安全(也最无用)的指令就是NOP。它在程序中占一个字节，但是不做任何操作。它有时被编译器和汇编器用于将代码对齐到有效的地址边界。

第一条指令生成了三字节的机器代码。NOP指令就把第三条指令的地址对齐到双字边界(4的偶数倍)

x86处理器被设置为从双字节的偶数倍地址处加载代码和数据，这使得加载速度更快

指令

MOV

**MOV destination,source**
目的操作数内容会发生改变，而源操作数不会

  • 两个操作数必须同样大小
  • 两个操作数不能同时为内存操作数
  • 指令指针寄存器不能为目标操作数

    在64为中，如果将32位尝试移入rax，那么高32位清除为0
    如果将32为内存操作数移入eax，rax高32位清0，但是操作8位，16位高位不受影响

偏移量操作

MOVZX

MOVZX(进行全零扩展并传送)，将源操作数传送到目的操作数，并将其扩展到16位或者32位(只用于无符号整数)

MOVSX

MOVZX(进行符号扩展并传送)，将源操作数传送到目的操作数，并将其扩展到16位或者32位(只用于有符号整数)

LAHF/SAHF

LAHF(加载状态标志位到AH)指令将寄存器EFLAGS的低字节复制到AH。被复制的标志位包括:符号标志位、零标志位、辅助进位标志、奇偶标志位，进位标志位

SAHF(保存AH内容到状态标志位)指令将AH的内容复制到EFLAGS(或RFLAGS)寄存器低字节

XCHG

XCHG指令，交换两个操作数内容

除了不使用立即数外，其他要求与mov一样
如果要交换两个内存操作数的值，则要用寄存器作为临时容器

INC/DEC

INC(加)和DEC(减)分别表示寄存器或内存操作数加一和减一
INC和DEC不会影响进位标志位(CF,CY)，但会影响辅助进位标志位(AC)

ADD/SUB

ADD指令将长度相同的源操作数和目的操作数进行相加操作,相加的和存在目的操作数中
add dest,source
SUB指令将目的操作数减去源操作数的差存在目的操作数中
sub dest,source

NEG

将二进制操作数转换位2进制补码，将操作数符号取反

JMP

JMP指令会无条件跳转到目的地址，该地址用代码标号来标识，并被汇编器转换为偏移地址
JMP dest
当CPU执行无条件跳转时，目标地址偏移量被送入指令指针寄存器，从而导致从新地址开始执行

LOOP

LOOP指令，按照ECX计数器循环，将程序块重复特定次数。ECX自动成为计数器，每循环一次自动减1
如果ECX等于0，将停止跳转。LOOP执行顺序：ECX减去1，与0比较，若不等，跳转，等于，停止跳转

作为一般规则，多余两成循环嵌套难以编写，若有需要，可以将一些内循环用子程序实现

PUSH/POP

PUSH指令，减少ESP的值，并将源操作数放入堆栈，如果原操作数是16位，ESP减2，是32位，ESP减4，8位减去1
POP指令，首先把ESP指向堆栈的元素的内容复制到一个16位或者32位的目的操作数中，然后把ESP的值增加2或者4

PUSHFD/POPFD

PUSHFD指令把32位寄存器EFLAGS压入堆栈，POPFD指令把栈顶单元内容弹出到EFLAGS寄存器

mov指令不能把EFLAGS寄存器的值传送

一种不容易出错保存标志寄存器值的方法

PUSHAD/PUSHA/POPAD/POPA

PUSHAD指令按照EAX、EBX、ECX、EDX、ESP(执行PUSHAD之前的值)、EBP、ESI、EDI将所有通用寄存器按这个顺序入栈。POPAD按照相反的顺序出栈，恢复寄存器的值
PUSHA指令将所有十六位通用寄存器按照顺序(AX,BX,CX,DX,SP,BP,SI,DI)入栈，POPA按照相反顺序出栈

一般使用PUSHAD和POPAD是为了备份某一段可能修改寄存器值得代码之前的寄存器值，然后在这段结束后恢复之前的寄存器

CALL/RET

CALL指令调用一个过程，使处理器从新的内存地址开始执行
过程使用RET指令将处理器回到该过程被调用的程序点上
CALL指令将返回地址压入堆栈，在把被调用过程的地址复制到指令指针寄存器中。当过程准备返回时，它的RET指令从堆栈中把返回地址弹到指令指针寄存器

布尔指令

AND 源操作数与目的操作数进行逻辑与
(将字符转换为大写只需与11011111进行AND即可转换为大写)
OR 逻辑或
XOR 逻辑异或(一个数a与一个数b异或两次结果为a。与0异或结果为本身【检查奇偶校检位】)
NOT 对目标操作数进行逻辑非
TEST 进行逻辑与，并适当设置CPU标志位(不修改目标操作数)
CMP 从目的操作数减去源操作的隐含减法操作，并不修改任何值.操作的结果会对标志造成影响。

AND、OR、XOR，俩个操作数必须同样大小
AND、OR、XOR、TEST指令清除OF(OV)和CF(CY)，其他标志位以结果计算
NOT指令不影响标志位
布尔指令影响零标志位(ZF,ZR)、进位标志位(CF,CY)、符号标志位(SF,PL)、溢出标志位(OF,OV)和奇偶标志位(PF,PE)

  • 操作结果为0,置ZF为1
  • 操作使目标操作数有进位时，CF置为1
  • PF是目标操作数最高位符号位的副本，如果标志位为则是负号，否则不是
  • 指令产生的数大于目标操作数范围时OF置1
  • 指令使得目标操作数低字节1个数为偶数个时，PF置1

64位下，如果源操作数低于32位，那么64位目标操作数进行操作而改变，若等于32位则只有低32位进行操作

CMP指令与标志位
当比较的是两个无符号整数时
**dnum < snum ZF=0,CF=1**
**dnum > snum ZF=0,CF=0**
**dnum = snum ZF=1,CF=0**
当为有符号整数时:
**dnum < snum SF != OF**
**dnum > snum SF = OF**
**dnum = snum ZF=1**

EFLAGS相关指令

STC指令使进位标志位(CF)置1、CLC指令清除进位标志位(CF)
CLD方向标志位(DF)清零(正向)、SLD方向标志位(DF)置1(反向)

Jcond

基于特定标志位跳转
JC 进位跳转 CF(CY)=1
JNC 无进位跳转 CF(CY)=0
JZ 为0跳转 ZF(ZR)=1
JNZ 非零跳转 ZF(ZR)=0
JO 溢出跳转 OF(OV)=1
JNO 非溢出跳转 OF(OV)=0
JS 有符号跳转 SF(PL)=1
JNS 无符号跳转 SF(PL)=0
JP 偶校检跳转 PF(PE)=1
JNP 奇校检跳转 PF(PE)=0
基于相等性跳转
JE 相等跳转(cmp x,y x=y) 相当于jz
JNE 不相等跳转(cmp x,y x!=y)相当于jnz
JCXZ CX=0跳转
JECXZ ECX=0跳转
JRCXZ RCX=0跳转
基于无符号数比较跳转
**JA**(大于跳转)/**JNBE**(不小于或等于跳转)
**JAE**(大于或等于跳转)/**JNB****(**不小于跳转)
**JB**(小于跳转)/**JNAE**(不大于或等于)
**JBE**(小于或等于跳转)/**JNA**(不大于跳转)
基于有符号数比较跳转
**JG**(大于跳转)/**JNLE**(不小于或等于跳转)
**JGE**(大于或等于跳转)/**JNL****(**不小于跳转)
**JL**(小于跳转)/**JNGE**(不大于或等于)
**JLE**(小于或等于跳转)/**JNG**(不大于跳转)

LOOPcond

**LOOPZ** 与LOOP一样，附加条件：为零 ZF(ZR)=1
**LOOPE** 相等跳转。与LOOPZ一样，
**LOOPNZ**(非零跳转 ZF(ZR)=0)/**LOOPNE**(不相等跳转)

移位和循环移位指令

SHL 左移，最后左移出位复制到CF标志位,低位0填充
将一个无符号数左移(向MSB移)进行位元乘法，即将该数乘以2n n为移位次数
SHR 右移，最后右移出位复制到CF标志位,高位0填充
将一个无符号数右移(向LSB移)进行位元除法，即将该数除以2n n为移位次数
SAL 算术左移
SAR 算术右移 高位填充符号位，执行有符号数除法
ROL 循环左移，所有位左移，最高位复制到CF和最低位
ROR 循环右移，所有位右移，最低位复制到CF和最高位
RCL 带进位循环左移，每一位左移，最高位复制到CF，CF值复制到最低位
RCR 带进位循环右移
SHLD 双精度左移，将目的操作数左移指定位数，空位由源操作数的最高位填充。源操作数不变SHLD de so c，CF同上
SHRD 双精度右移

CL寄存器指定的位数
逻辑移位，空出数据用0填充
算术移位，空出数据用原数据符号位填充
有符号数溢出：移动一位导致产生的结果超过目的操作数范围，OF置1，即符号位取反，如果移动次数大于1，则OF无定义

MUL

MUL(无符号乘法)，乘数与被乘数大小保持一致，可以使用内存操作数和寄存器但不能使用立即数

被乘数 乘数 乘积
AL reg/mem8 AX
AX reg/mem16 DX:AX
EAX reg/mem32 EDX:EAX

如果乘积的高办部分不为0，则CF,OF=1，若为0，CF=0

IMUL

有符号整数乘法，有三种格式

  1. 单操作数格式，同MUL。结果为高半部分是低半部分的符号扩展，若不是则OF,CF=1
  2. 双操作数格式，目的操作数必须是寄存器，dreg为16位时op可以是16reg、op，8位op；dreg为32位时，op可以是32位reg、op，8位操作数。在该格式下，会按照目的操作数大小来截取乘积，如果被丢弃的是有效位，那么CF,OF=1
  3. 三操作数格式，目的操作数必须是寄存器，第二三操作数相乘，乘积放在目的操作数中。格式有
    IMUL reg16,reg16/mem16,imm8/16
    IMUL reg32,reg32/mem32,imm8/32
    在该格式下，会按照目的操作数大小来截取乘积，如果被丢弃的是有效位，那么CF,OF=1

DIV

DIV无符号除法指令，其中单寄存器或内存操作数是除数

被除数 除数 商 余数
AX reg/mem8 AL AH
DX:AX reg/mem16 AX DX
EDX:EAX reg/mem32 EAX EDX

DX,EDX是被除数高位部分，使用DIV指令前需要清0

IDIV与符号扩展指令

有符号除法指令IDIV，该指令与DIV完全相同，只是在进行除法前，必须对被除数进行符号扩展
符号扩展：将一个数的的最高位复制到包含该数的变量或寄存器所有高位中

符号扩展指令
CBW 字节转字
CWD 字转双字
CDQ 双字转四字

如果除法操作生成的商不适合目的操作数，如超过大小，那么会产生除法溢出，将会导致处理器异常并暂停程序

扩展加减法

ADC(带进位加法)指令将源操作数和进位标志位值都与目标操作数相加。格式与ADD一样，且操作数大小必须相同
SBB(带借位减法)指令从目的操作数中减去源操作数和进位标志位值

ASCII和非压缩十进制运算

AAA 执行加法后进行ASCII调整
AAS 执行减法后进行ASCII调整（差是负数是才有调整必要）
AAM 执行乘法后进行ASCII调整
AAD 执行除法后进行ASCII调整

ASCII十进制数和非压缩十进制数，每个数字都占一字节
3402存放

AAA指令调整ADD或ADC指令的二进制运算结果。设两个ASCII数字相加，其结果存放在AL中，则AAA将AL转换为两个非压缩十进制数字存入AH和AL。成为非压缩格式，使用or与30h异或即可转为ASCII码

如果al的低4位是在0到9之间，保留低4位，清除高4位，如果al的低4位在10到15之间，则通过加6，来使得低4位在0到9之间，然后再对高4位清零。
如果al的低4位是在0到9之间，ah值不变，CF和AF标志清零，否则，ah=ah+1，并设置CF和AF标志

压缩十进制运算

DAA 执行加法后的十进制调整
DAS 执行减法后的十进制调整

LEA

LEA返回间接操作数的地址
LEA esi,[ebp - 30],堆栈中不能使用OFFSET获取地址，可以使用LEA获取地址

ENTER\LEAVE

ENTER指令为被调用过程自动创建堆栈帧。它为局部变量保留空间，把EBP入栈
执行的操作有：push ebp``mov ebp,esi``sub esp,numbytes
LEAVE指令，结束一个过程的堆栈帧。恢复被调用的ESP，EBP的值，

字符串指令

MOVSB,MOVSW,MOVSD 传送字符串数据:将ESI寻址的内存数据复制到EDI寻址的内存位置
CMPSB,CMPSW,CMPSD 比较字符串，比较由ESI和EDI寻址的内存数据
SCASB,SCASW,SCASD 扫描字符串，比较累加器(AL,AX,EAX)与EDI寻址的内存数据
STOSB,STOSW,STOSD 保存字符串数据,将累加器内容保存到EDI寻址的内存位置
LODSB,LODSW,LODSD 从字符串加载到累加器,将ESI寻址的内容加载到累加器

就其自身而言，字符串基本指令只能处理一个或一队内存数值。如果加上重复前缀，指令就可以用ECX作为计数器重复执行。重复前缀使得单条指令能够处理整个数组

REP ECX > 0时重复
REPZ,REPE ZF = 1，且ECX > 0 重复
REPNZ,REPNE ZF = 0，且ECX > 0 重复
